Support

Questions, problems or ideas: write to macapps.support@icloud.com. Mention your macOS version and what you see.

Getting started

  1. Open TeamPulse. In the Welcome window, click Sign in with GitHub, copy the code, paste it on the GitHub page that opens and click Authorize. Or try everything first with Try with sample data.
  2. Choose the organization to watch.
  3. Add widgets: Control-click the desktop, choose Edit Widgets, search for TeamPulse and drag a widget onto the desktop.
  4. For the full-desktop dashboard, click the TeamPulse icon in the menu bar and switch on Desktop dashboard.

"Waiting for your organization to approve TeamPulse"

Many organizations only let approved apps read their private data. TeamPulse then shows nothing rather than wrong, empty results. On the waiting screen, click Open TeamPulse on GitHub to request access, and send an organization owner the ready-made message from Copy message for an owner. Owners approve it under Organization settings › Third-party access › OAuth app policy. TeamPulse checks every two minutes and starts on its own. A personal access token isn't affected by this approval, if you prefer that.

Signing in with a personal access token

In the Welcome window, choose Use a token. Create a classic token with the repo, read:org and read:user scopes. If your organization uses single sign-on, click Configure SSO next to the token on GitHub and authorize the organization.

Widgets

  • Each widget card has a blue switch button at the top right that shows the next list. To fix a widget to one list, Control-click it and choose Edit "TeamPulse".
  • Widgets update when TeamPulse refreshes, so keep it running: Settings › General › Open at login.
  • macOS dims desktop widgets while another app is in front; System Settings › Desktop & Dock › Dim widgets on desktop controls this.

How often it refreshes

Your own PRs every 3 minutes, org activity every 15 minutes, and delivery, security and CI health every hour, well within GitHub's hourly API limit. Click the refresh button to update now.

Some cards say "needs org admin access"

Self-hosted runners and outside collaborators need organization admin access, billing needs owner or billing manager access, and security alerts need the features enabled and access to them. TeamPulse shows everything else and notes what it couldn't read.

Signing out

Settings › Account › Sign out deletes your sign-in and all fetched data from your Mac. To revoke TeamPulse's access on GitHub too, open GitHub › Settings › Applications.
